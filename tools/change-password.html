Ganti Password & Enkripsi Ulang

Utilitas lokal: mendekripsi file buku dengan password lama, lalu mengenkripsi ulang dengan password baru — semuanya di browser Anda, tanpa mengirim apa pun ke server.

Simpan cadangan dulu! Salin seluruh folder books/ (dan PDF asli Anda) ke tempat aman sebelum menimpa file. Jika proses gagal di tengah jalan, cadangan ini penyelamat Anda. Password awal piya 123 hanya untuk demonstrasi — gunakan password kuat untuk dokumen privat.

1. Password

2. File Buku Terenkripsi

Pilih satu atau beberapa file .piyapdf dari folder books/ (bisa multi-select).

3. Hasil

Setelah semua file diunduh:

  1. Timpa file lama di folder books/ dengan file hasil unduhan (nama file tetap sama).
  2. Ganti data/auth.json dengan auth.json baru (ini yang mengatur password login website).
  3. Jika Anda memuat catalog.json, timpa juga data/catalog.json dengan hasil unduhan.
  4. Commit & push ke GitHub, tunggu Pages terbarui, lalu uji login dengan password baru.

Perubahan hanya berlaku online setelah Anda git commit & git push.

Cara Kerja & Keamanan

  • File .piyapdf didekripsi di memori browser memakai password lama (PBKDF2-SHA256 + AES-256-GCM).
  • Isi PDF yang sudah terbuka langsung dienkripsi ulang dengan password baru (salt & IV baru yang acak) — bukan sekadar mengganti teks password di konfigurasi.
  • auth.json baru dibuat dari password baru (verifikator PBKDF2, bukan teks password).
  • Password dan dokumen tidak disimpan di localStorage dan tidak dikirim ke layanan eksternal.
  • Format berkas tetap sama dengan yang dipakai pembaca website, sehingga buku tetap bisa dibuka setelah ganti password.
