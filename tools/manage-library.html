Kelola Koleksi Buku

Utilitas ini berjalan sepenuhnya di browser Anda. File PDF tidak dikirim ke mana pun; enkripsi terjadi di komputer ini. Hasilnya lalu Anda unggah ke repository GitHub.

Penting: jangan pernah mengunggah PDF asli (belum terenkripsi) ke repository publik. Selalu unggah hanya berkas .piyapdf hasil enkripsi dari halaman ini. Simpan PDF asli sebagai cadangan di luar repository.

1. Katalog

Muat data/catalog.json yang sudah ada agar daftar buku bisa diperbarui. Jika ini buku pertama, biarkan kosong.

Katalog belum dimuat.

2. Tambah Buku (Enkripsi PDF)

Gunakan password yang sama dengan password login website agar buku bisa dibuka setelah login. Password awal adalah piya 123 — gantilah sebelum dokumen privat (lihat halaman Ganti Password).

3. Struktur Folder & Cara Menerbitkan

  1. Setelah menekan Enkripsi & Siapkan Unduhan, browser mengunduh berkas-berkas hasil. Letakkan di repository dengan struktur berikut:
Flipbooksnya-Piya/
├── books/
│   ├── ID-BUKU.piyapdf        <- hasil unduhan (file terenkripsi)
│   └── covers/
│       └── ID-BUKU.jpg          <- hasil unduhan (cover)
├── data/
│   ├── catalog.json            <- hasil unduhan (ganti yang lama)
│   └── auth.json
└── ...
  1. Buka terminal di folder repository, lalu commit dan push:
git add books data
git commit -m "Tambah buku baru"
git push
  1. Tunggu GitHub Pages selesai memperbarui (± 1 menit), lalu buka website. Buku baru akan tampil di koleksi.
  2. Menghapus buku: hapus entri di daftar bawah katalog (tombol Hapus), unduh catalog.json baru, hapus juga file di books/, lalu push.
  3. Mengganti buku: proses ulang PDF dengan ID yang sama, timpa file lama, lalu push.

Perubahan di halaman ini tidak langsung tersimpan online. Website hanya berubah setelah Anda commit & push ke GitHub.

Catatan Keamanan

  • Enkripsi memakai AES-256-GCM dengan kunci diturunkan dari password lewat PBKDF2-SHA256 (salt acak per file, IV unik).
  • Password tidak pernah dikirim ke layanan eksternal dan tidak disimpan di penyimpanan browser.
  • Password lemah tetap rentan terhadap penebakan. Gunakan password panjang untuk dokumen sensitif.
  • PDF asli yang belum terenkripsi tidak boleh masuk repository publik.
